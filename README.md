## Project Structure

- `index.html` — Page structure and semantic sections (Navigation, Hero, Selected Work, Studio Philosophy, Services, Contact, Footer, and Lightbox modal).
- `style.css` — Luxury editorial visual system, warm ivory and cream palette, *Cormorant Garamond* and *Plus Jakarta Sans* typography, responsive grid, and restrained motion rules.
- `script.js` — Smooth anchor scrolling, mobile drawer, hero plate switcher, lightbox gallery controls, click-to-copy email action, scroll reveals, bounded parallax, and Three.js architectural relief sculpture.
- `README.md` — Project overview and setup instructions.

## Setup & Local Preview

1. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
2. Place your furniture and interior concept image files (`1000090142.jpg`, `1000090143.jpg`, `1000090144.jpg`, `1000090154.jpg`, `1000090155.jpg`) in that same folder.
3. Open `index.html` in a browser or serve the directory using a local static server (for example, `python -m http.server 8000`).
